# AI-Powered Smart Resume Analyzer

An AI-powered resume analysis system that helps candidates evaluate their resumes, compare them with job descriptions, identify skill gaps, and improve their chances of getting shortlisted.

## 🚀 Features

* 📄 Upload and analyze resumes
* 🤖 AI-powered resume analysis
* 🎯 Job description matching
* 📊 Resume match score
* 🔍 Skill and keyword extraction
* ⚠️ Identify missing skills and keywords
* 💡 Personalized resume improvement suggestions
* 📈 Resume quality analysis
* 📑 Support for common resume formats
* 🖥️ Simple and user-friendly interface

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Backend:** Python, FastAPI
* **AI/ML:** NLP, Machine Learning
* **Database:** MongoDB
* **Resume Processing:** PDF/DOCX Parsing, OCR
* **Version Control:** Git & GitHub

## 🔄 How It Works

```text
Upload Resume
      ↓
Resume Parsing
      ↓
Text Extraction
      ↓
AI/NLP Analysis
      ↓
Skill & Keyword Extraction
      ↓

      ↓
```

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Ai-Powered-Smart-Resume-Analyzer.git
cd Ai-Powered-Smart-Resume-Analyzer
```

### 2. Create a Virtual Environment

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Backend

```bash
uvicorn main:app --reload
```

### 5. Run the Frontend

```bash
npm install
npm run dev
```
